REST API Endpoints

SentimentIQ exposes a simple JSON API so you can integrate sentiment analysis directly into your own applications.

POST /api/analyze

Analyse a single text string and get full sentiment results instantly.

Input
JSON body with a text field containing your text
Returns
Final sentiment, intensity level, VADER scores, TextBlob polarity, emotion breakdown, readability scores, top keywords
final_sentimentpositive / negative / neutral / mixed
intensityStrongly Positive → Strongly Negative
vader.compoundFloat from -1.0 to +1.0
emotions.dominantjoy / anger / sadness / fear …
readability.reading_levelEasy / Difficult / Very Easy …

GET /api/dashboard

Retrieve aggregated analytics data for all stored analyses, with optional date filtering.

Optional Filters
?from=YYYY-MM-DD and ?to=YYYY-MM-DD to scope results to a date range
Returns
Total count, sentiment distribution, daily trend, analyser comparison, word frequencies, avg compound and subjectivity
totalNumber of records in range
sentiment_distributionCounts per positive/negative/neutral
trendDaily sentiment counts (time series)
word_frequenciesTop 100 lemma frequencies
avg_compoundAverage VADER compound score
